# 灵枢 SenseHub 产品档位说明

> **文档版本**：v1.0（商业化交付版）  
> **生效范围**：灵枢 Console · 灵枢 Studio · 灵枢 Code · Token Plan  
> **技术门控**：`sensehub/licensing/tier.py`（运行时按 **生效档位** `lite` / `pro` / `max` 校验）

---

## 1. 档位体系概览

灵枢 SenseHub 采用 **四档订阅套餐** 对外销售，运行时权限按 **三档生效档位** 门控：

| 订阅套餐 | 生效档位 | 定位 | 典型用户 |
|----------|----------|------|----------|
| **Lite** | `lite` | 入门体验 | 个人试用、轻量自动化 |
| **Standard** | `pro` | 标准专业 | 日常办公、多模态交互 |
| **Pro** | `pro` | 专业开发 | 开发者、高频 API 与编程工具接入 |
| **Max** | `max` | 旗舰全量 | 深度自动化、虚拟屏与多脑协作 |

**说明**：Standard 与 Pro 共享同一套运行时能力（`pro`），差异体现在 **Token 额度、专属 API 服务、编程工具接入与商业权益**。Max 解锁全部高级能力。

积分订阅价格与周期见官网 **Token Plan** 页面及控制台「积分兑换」；默认目录与后端 `list_subscription_plans()` 一致。

## 4. 授权与门控实现

| 机制 | 说明 |
|------|------|
| 订阅状态 | 用户钱包 `tier` + `tier_expires_at`；积分兑换套餐后写入 |
| 生效档位 | `lite` / `pro` / `max`；Standard、Pro 均映射为 `pro` |
| 功能门控 | `feature_enabled()` 校验虚拟屏、多 Agent、流式语音等 |
| 用量门控 | Lite 文本指令每日 20 次；Token 按套餐额度统计 |
| 超额处理 | Web UI 提示升级或充值积分；不静默降级为不安全模式 |
| 开发环境 | `LICENSE_TIER` 环境变量可设为 `max` 用于全功能联调 |

档位枚举与特性表见 `sensehub/licensing/tier.py` 中 `TIER_FEATURES`、`TIER_LIMITS`。
