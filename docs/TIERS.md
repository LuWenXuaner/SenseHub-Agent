# 灵枢 Agent 档位对照（Lite / Pro / Max）

三档通过 `sensehub/licensing/` 中间件统一门控。用户可在 Web 控制台查看当前档位与限额。

---

## 1. 功能对照总表

| 维度 | Lite（免费） | Pro | Max |
|------|-------------|-----|-----|
| **文本指令** | 每日 20 次 | 无限 | 无限 |
| **语音 ASR** | 离线 Whisper small | 流式 + 更大模型 | FunASR/Whisper large，最低延迟 |
| **语音快捷命令** | 最多 10 条 | 无限 | 无限 + 自定义唤醒词 |
| **TTS 反馈** | Edge TTS 基础 | Edge TTS | Edge TTS + Azure 低延迟（可选） |
| **视觉** | 摄像头预览 + 人员检测 | + 手势规则 + 场景事件 | + 虚拟屏 + VLM 深度理解 |
| **LLM** | 用户自填 API Key 或平台限额小模型 | 平台增强模型额度 | 最强模型 + 多模型协作 |
| **桌面自动化** | 打开应用、键鼠、截图 | + Playwright 复杂流程 | + 自定义宏、批量任务 |
| **规则引擎** | 最多 3 条 | 50 条 | 无限 + AND/OR 组合条件 |
| **远程访问** | 仅 localhost | 局域网 + IP 白名单 | 局域网 + 可选安全隧道 |
| **审计日志** | 保留 7 天 | 保留 90 天 | 保留 1 年 + 导出 |
| **支持** | 社区 | 邮件 | 优先 |

## 3. 授权实现（规划）

| 机制 | 说明 |
|------|------|
| License 文件 | 本地加密文件，含 tier、过期时间、签名 |
| 在线校验 | 可选，启动或每日校验 |
| 门控位置 | FastAPI 中间件 + 规则引擎 + LLM 路由 |
| 超额提示 | Web UI 弹窗引导升级 |

档位枚举：`lite` | `pro` | `max`（默认开发环境可用 `max` 跳过限制）。
